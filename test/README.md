# 测试范围

统一使用 Vitest；Bun 负责依赖安装和脚本执行。测试提供自己的规则，不固定默认规则数量、id 或选择器，也不设覆盖率门槛。

## Node 单元测试：18 项

| 文件 | 项数 | 行为 |
| --- | ---: | --- |
| `unit/matching.test.js` | 6 | 普通词命中/放行；字段级正则与 `/g` 回归；页面分类；作用域；逗号与正则拆分；正则往返与坏正则隔离 |
| `unit/duration.test.js` | 3 | 时长解析/格式；阈值边界与作用域；懒加载时长重新查找 |
| `unit/storage.test.js` | 8 | 首次种子与本地规则优先；配置往返；导入清理；扩展 v2–v4 迁移与备份；存储同步；临时词有效期、过滤、清理与同步 |
| `unit/extension-package.test.js` | 1 | manifest 能加载所有内容脚本模块，无失效路径 |

## jsdom 集成测试：14 项

| 文件 | 项数 | 行为 |
| --- | ---: | --- |
| `dom/engine.test.js` | 4 | HTML 字段提取与动态插入；作用域/SPA 分类；时长提取与恢复；坏选择器隔离与直接隐藏 |
| `dom/panel.test.js` | 10 | 添加保存重载；筛选删除不丢隐藏词；展开/收起/关闭；规则和总开关启停；纯时长规则编辑删除；文件导出/导入与坏配置拒绝；远端存储事件和临时词生命周期；筛选计数和清空撤销；时长撤销保留到期时间；保存等待/失败/重试与期间编辑 |

这些测试运行真实 `main.js`、面板、选择器、引擎和 MutationObserver；仅浏览器扩展存储、文件下载/上传边界与计时器使用模拟。每次挂载重置模块、DOM、观察器和定时器，防止相互污染。临时词过期采用模拟时钟或已过期存储数据，不等待真实一小时。

`fixtures/cards.html` 是虚构的 `.card` / `.title` / `.author` 卡片，不复制 B 站布局。默认规则更新不需要改写 fixture。

## 自动测试的边界

jsdom 不执行实际布局，不验证滚动条数量、按钮坐标、动画效果、Chrome/Edge 扩展加载或真正的跨标签浏览器事件。DOM 测试只检查展开状态和模拟存储变化后的响应。文件导出检查真实生成的内容，下载本身由模拟替代。

发布前用 Chrome 或 Edge 手动检查：解压安装、实际页面规则、动态内容、展开后单滚动条和输入行固定、面板文件导入导出、两个标签页同步。通过 Vitest 不等于完成这些验收。

## 执行

```sh
bun run test        # Vitest 一次性执行 32 项测试
bun run test:watch  # 开发时持续运行
bun run check       # ESLint（含格式）+ Vitest
```

不要使用 `bun test`：它会调用 Bun 自带测试器；本项目使用的是 `bun run test`。
