# 哔哩哔哩 - 屏蔽指定内容（浏览器扩展版 v5）

按 **屏蔽词（关键字/正则，纯文字匹配）** 屏蔽 bilibili 的视频卡片；支持 **页面作用域**（全局/搜索/空间/播放/收藏，其余页面不触发）、**过期式临时屏蔽**（默认 24 小时）、**时长按蔽**（屏蔽过短/过长视频）、**可编辑的选择器规则**（B 站改版自行修复，无需改代码）、多标签页实时同步。

本扩展源自油猴脚本 [哔哩哔哩 - 屏蔽指定内容](https://greasyfork.org/zh-CN/scripts/397669)（v4.8.0，作者 pana，GPL-3.0+），v5 起从「逐字对等」转向「按需重构」，删除了大量少用功能（见 Changelog）。

- 许可证：**GPL-3.0-or-later**
- 目标浏览器：**Edge / Chrome（Manifest V3）**，无构建步骤、零运行时依赖

## 安装（Edge）

1. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`）
2. 开启左下角「开发人员模式」
3. 点击「加载解压缩的扩展」，选择本项目根目录（含 `manifest.json`）

## 使用

鼠标移到页面 **右下角** 弹出蓝色圆形「屏蔽」按钮，点击打开设置面板：

- **通用**：总开关
- **分类标签页**：面板顶部在 全局/搜索/空间/播放/收藏 之间切换，下方管理当前分类的内容；「全局」屏蔽词覆盖全部已匹配页面（首页 feed 等未匹配页面不触发屏蔽）
- **屏蔽词**：统一列表，每个词同时作用于标题与 UP 主名——普通词对标题「包含」匹配、对 UP 主名「精确」匹配；`/Pattern/Modifier` 正则在两者上都尝试匹配
- **时长按蔽**：与屏蔽词并列的词条组，可添加多条「短于/长于 N 秒」（输入框右侧实时预览 `22:24` / `01:17:44` 格式），卡片时长满足任一条即屏蔽
- **临时**：勾选后词条（屏蔽词/时长均可）按所选有效期保存（1 小时/6 小时/24 小时/7 天，默认 24 小时）——独立存储、刷新不丢、跨标签页同步，到期自动清除；分类页内「清空临时词」可立即移除
- **规则**：每个分类页底部同时展示**内置规则**（带「内置」标记，可编辑/删除）与自定义规则，默认收起，点「编辑」展开。规则 = 卡片容器选择器 + 文字选择器（可多个，提取文本交给屏蔽词匹配）+ 可选时长选择器；模式两档：「按屏蔽词过滤」（需至少一个文字选择器）与「直接隐藏」。每条规则带命中统计徽标「找到 N · 隐藏 M」，有命中绿色高亮——长期「未命中」的规则多半已被 B 站改版淘汰，改选择器或补一条即可
- 底部按钮：「保存并关闭」/「仅保存」（闪「已保存」）/「取消」（丢弃未保存编辑）/「导出设置」（下载全量 JSON，含全部规则）/「导入设置」（选择 JSON 文件导入，自动迁移旧版本）
- **多标签页同步**：任一标签页保存后其余已打开页面实时生效（临时词条同步走独立存储键）

### 从旧版本 / 油猴脚本迁移

存储形状在 v5 升级为 v4，首次加载自动迁移并按原版本写入备份键（`bilibili_config_v1_backup` / `…_v2_backup` / `…_v3_backup`，被丢弃/合并前的原样可从备份键找回）。也可手动：Tampermonkey 仪表盘 → 原脚本「储存」页 → 复制 `bilibili_config` JSON → 打开扩展导入页 `chrome-extension://<扩展ID>/src/tools/import-export.html` 粘贴导入（扩展 ID 可在任意 bilibili 页面控制台执行 `document.documentElement.dataset.bilibanId` 查看）。导入页「导出」输出全量设置（屏蔽词、时长词条、全部内置/自定义规则），可用于备份或在设备间迁移。

## Changelog

### 6.0.0（破坏性变更：分类重定义）

- **分类重定义**（旧数据自动迁移：video/home → 播放，dynamics → 全局）：
  - **搜索**：`search.bilibili.com/*`
  - **空间**：`space.bilibili.com/{uid}/upload/video`（投稿视频页）
  - **播放**：`www.bilibili.com/video/*`、`/bangumi/*`、`/list/ml*`（收藏夹播放）、`/list/watchlater`（稍后再看播放）
  - **收藏**：`www.bilibili.com/watchlater/*`（稍后再看列表）、`space.bilibili.com/{uid}/favlist`
  - **其他页面（首页 feed、频道、热门、动态等）不再触发屏蔽**——稍后再看/收藏夹列表等个人内容默认绝不误伤；需要新页面时改代码加分类
- **删除「首页」分类**与首页特殊逻辑（轮播/排行榜）；内置规则集随之精简为 8 条并重排作用域（`builtinVersion` 升至 3，旧固化集自动换新）
- **「全局」面板仅保留屏蔽词**；时长词条与规则（内置+自定义）归各具体分类管理

### 5.6.0

- **修复：规则「编辑」按钮无反应**——编辑区 `display:flex` 声明在样式表中覆盖了隐藏态，导致编辑区常开且切换失效；现默认收起，点「编辑」才展开
- **导入/导出改为面板内文件直传**：「导出设置」直接下载 `biliban-settings.json`（全量，含全部规则），「导入设置」选择 JSON 文件即导入（自动迁移旧版本形状）。不再打开扩展内部页，规避 Edge 的 `ERR_BLOCKED_BY_CLIENT` 拦截

### 5.5.0

- **规则模型重构（纯文字匹配）**：每条规则 = 卡片容器选择器 + **文字选择器数组（可多个）** + 可选时长选择器；UP 主选择器废弃（文字选择器可指向 UP 主名元素，统一走屏蔽词匹配）
- **移除 BV→UP 主名反查**：不再请求 bilibili API，infoRecord 缓存作废；仅有链接无文字的推荐位不再处理
- **内置规则精简 23 → 9**：裁掉失效旧版布局（.video-card-common/.groom-module/.rank-wrap/.manga-* 等）；新增 `builtinVersion` 机制——扩展升级后内置集自动更新，除非你编辑过（编辑过的版本继续保留）
- **规则行默认收起**：概览显示选择器 + 统计徽标 + 编辑/删除，点「编辑」展开编辑区，不再整屏输入框
- **时长输入按秒**：右侧实时预览 B 站格式（`22:24` / `01:17:44`）
- **临时屏蔽改过期制**：默认 24 小时（可选 1 小时/6 小时/24 小时/7 天），独立存储键、刷新不丢、跨标签页同步，到期自动清除
- **面板底部新增「导入/导出」按钮**：直达导入导出页，全量备份/迁移设置（含全部规则）

### 5.4.0

- **修复**：规则行「启用」勾选无法点击（label 未绑定 `for`）
- **时长词条按秒输入**：阈值输入改为秒（适配几秒/十几秒的短视频屏蔽），chip 智能显示 `短于 15 秒` / `长于 90 分钟`
- **全量导出**：导入导出页的导出包含全部设置——屏蔽词、时长词条、全部内置规则与自定义规则（内置规则未编辑过时以代码默认补全，导出自包含）
- **样式重排**：面板输入行/规则行/标签栏改用 flex + gap，控件不再挤压；分类页滚动区微调

### 5.3.0

- **空间分类回归**：`space.bilibili.com` 重新成为一级分类（面板第 5 个标签页），空间投稿按「空间」或「全局」词条屏蔽
- **内置规则可操作**：分类页中的内置规则行可直接编辑选择器、改模式、启用开关或删除；保存后写回 `builtinRules`（首次保存即固化当前内置规则集；此后扩展升级不会自动覆盖你的修改。删除所有内置规则 = 全部停用）
- **规则选择器扩展点**：规则新增「时长选择器」字段（在「更多」里），精确指定卡片内时长文本位置；留空则沿用全卡片启发式探测。后续新选择器类型按同一模式追加
- 修复：规则命中统计按轮覆盖写（不再无限累加）

### 5.2.0

- **分类精简**：面板标签页从 6 个减为 4 个（全局/首页/视频页/搜索）；动态（含 opus）与空间页归为内部分类，由全局词条覆盖；旧数据中的 dynamics/space 作用域自动回落为全局

- **内置规则展示**：分类页底部列出该分类的内置选择器规则（只读 + 「内置」标记）
- **规则命中统计**：面板内每条规则显示「找到 N · 隐藏 M」（本标签页本次加载），命中绿色高亮，便于识别失效规则

### 5.1.0

- 用户名与关键字合并为统一的「屏蔽词」列表：每个词同时过滤标题与 UP 主名（普通词：标题包含 / UP主名精确；正则：两者都匹配）；存储升级 v3，v2 的 usernames/keywords 自动合并迁移（备份至 `bilibili_config_v2_backup`）

### 5.0.0（破坏性变更）

**新增**
- 页面作用域：词条与规则按 全局/首页/视频页/搜索/动态/空间 分类生效
- 临时屏蔽：仅标签页内存，刷新即失，面板带「临时」徽标与「清空临时词」
- 时长按蔽：阈值分钟可调；调大阈值后已屏蔽卡片下一帧自动恢复

- `www.bilibili.com/opus/*` 新版动态页归入「动态」分类

**行为修复**
- 页面分类改为每次执行实时读取 `location.href`：修复 v4「首页 SPA 跳进视频页后视频页规则（如 `.ebox`）永不生效」的问题

## 开发

要求：[bun](https://bun.sh) ≥ 1.x；E2E 需要本机安装 Edge。

```bash
bun install          # 安装 dev 依赖（仅 @playwright/test）
bun test             # 单元测试（138 例）
bun run test:cov     # + 覆盖率（纯函数模块 ≥ 84%）
bun run e2e          # E2E：真实加载扩展，fixture 劫持 bilibili 域名（无头，不弹窗）
E2E_HEADED=1 bun run e2e   # 有头模式调试
```

### 目录结构

```
src/content/        # 内容脚本（ES Modules，经 entry.js 动态 import 加载）
  entry.js          # classic 入口（MV3 content_scripts 不支持 module）
  main.js           # 引导装配
  config/           # 存储：默认值/迁移(备份+写回)/作用域/正则序列化/chrome.storage 读写订阅/临时词条(过期制)
  engine/           # 屏蔽引擎：页面分类(URL 精确匹配)、词条判定、时长解析、规则循环、rAF 调度
  rules/            # 8 条内置选择器规则（作用域由单测钉死）
  panel/            # 设置面板：壳 + 分节（词条/时长/规则编辑器）+ 悬浮触发器 + 文件导入导出
src/tools/          # 导入导出迁移页（备用入口；面板底部按钮为主入口）
test/unit/          # bun test 单元测试
test/fixtures/      # E2E 用静态 bilibili 页面骨架（视频卡片/搜索/空间）
test/e2e/           # Playwright 规格（真实加载扩展 + 路由劫持）
```

### 测试策略

- **单元测试**：作用域/分类/判定/时长/迁移/临时词条/内置规则表等纯函数模块（覆盖率见 `bun run test:cov`）
- **E2E**：Playwright 以 `--load-extension` 真实加载扩展，用 `context.route()` 把真实 bilibili 域名应答为本地 fixture，保证 URL 分类与页面逻辑在真实域名上执行；API 请求被拦截以保证密封性
