# 哔哩哔哩 - 屏蔽指定内容（浏览器扩展版 v5）

按 **用户名 / 关键字 / 正则表达式** 屏蔽 bilibili 的视频卡片；支持 **页面作用域**（全局/首页/视频页/搜索/动态/空间）、**临时屏蔽**（仅当前标签页，刷新即失）、**时长按蔽**（屏蔽过短视频）、**自定义选择器规则**（B 站改版自行修复，无需改代码）、多标签页实时同步。

本扩展源自油猴脚本 [哔哩哔哩 - 屏蔽指定内容](https://greasyfork.org/zh-CN/scripts/397669)（v4.8.0，作者 pana，GPL-3.0+），v5 起从「逐字对等」转向「按需重构」，删除了大量少用功能（见 Changelog）。

- 许可证：**GPL-3.0-or-later**
- 目标浏览器：**Edge / Chrome（Manifest V3）**，无构建步骤、零运行时依赖

## 安装（Edge）

1. 打开 `edge://extensions`（Chrome 为 `chrome://extensions`）
2. 开启左下角「开发人员模式」
3. 点击「加载解压缩的扩展」，选择本项目根目录（含 `manifest.json`）

## 使用

鼠标移到页面 **右下角** 弹出蓝色圆形「屏蔽」按钮，点击打开设置面板：

- **通用**：总开关
- **分类标签页**：面板顶部在 全局/首页/视频页/搜索 之间切换，下方管理当前分类的内容；「全局」处处生效，动态/空间等其余页面由全局词条覆盖
- **屏蔽词**：统一列表，每个词同时作用于标题与 UP 主名——普通词对标题「包含」匹配、对 UP 主名「精确」匹配；`/Pattern/Modifier` 正则在两者上都尝试匹配
- **时长按蔽**：与屏蔽词并列的词条组，可添加多条「短于/长于 N 分钟」，卡片内出现 `1:23` / `1:02:03` 形式时长且满足任一条即屏蔽
- **临时**：勾选后词条（屏蔽词/时长均可）仅存于当前标签页内存——不落盘、不跨标签页同步、刷新页面即消失；分类页内「清空临时词」可立即移除
- **规则**：每个分类页底部同时展示**内置规则**（只读，带「内置」标记）与自定义规则；每条规则带命中统计徽标「找到 N · 隐藏 M」，有命中绿色高亮——长期「未命中」的内置规则多半已被 B 站改版淘汰，可用「添加规则」自行补一条；自定义规则模式两档：「按屏蔽词过滤」（需标题/UP主选择器之一）与「直接隐藏」
- 底部三按钮：「保存并关闭」/「仅保存」（闪「已保存」）/「取消」（丢弃未保存编辑）
- **多标签页同步**：任一标签页保存后其余已打开页面实时生效（临时词条除外）

### 从旧版本 / 油猴脚本迁移

存储形状在 v5 升级为 v4，首次加载自动迁移并按原版本写入备份键（`bilibili_config_v1_backup` / `…_v2_backup` / `…_v3_backup`，被丢弃/合并前的原样可从备份键找回）。也可手动：Tampermonkey 仪表盘 → 原脚本「储存」页 → 复制 `bilibili_config` JSON → 打开扩展导入页 `chrome-extension://<扩展ID>/src/tools/import-export.html` 粘贴导入（扩展 ID 可在任意 bilibili 页面控制台执行 `document.documentElement.dataset.bilibanId` 查看）。

## Changelog

### 5.2.0

- **分类精简**：面板标签页从 6 个减为 4 个（全局/首页/视频页/搜索）；动态（含 opus）与空间页归为内部分类，由全局词条覆盖；旧数据中的 dynamics/space 作用域自动回落为全局
- **时长按蔽词条化**：原全局开关改为词条组（短于/长于 N 分钟），可多条、随分类、支持临时；存储升级 v4（v3 的时长开关自动转为一条「短于」词条，备份至 `bilibili_config_v3_backup`）
- **内置规则展示**：分类页底部列出该分类的内置选择器规则（只读 + 「内置」标记）
- **规则命中统计**：面板内每条规则显示「找到 N · 隐藏 M」（本标签页本次加载），命中绿色高亮，便于识别失效规则

### 5.1.0

- 用户名与关键字合并为统一的「屏蔽词」列表：每个词同时过滤标题与 UP 主名（普通词：标题包含 / UP主名精确；正则：两者都匹配）；存储升级 v3，v2 的 usernames/keywords 自动合并迁移（备份至 `bilibili_config_v2_backup`）

### 5.0.0（破坏性变更）

**新增**
- 页面作用域：词条与规则按 全局/首页/视频页/搜索/动态/空间 分类生效
- 临时屏蔽：仅标签页内存，刷新即失，面板带「临时」徽标与「清空临时词」
- 时长按蔽：阈值分钟可调；调大阈值后已屏蔽卡片下一帧自动恢复
- 自定义规则编辑器：选择器试编译校验；match 模式要求至少一个标题/UP主选择器
- `www.bilibili.com/opus/*` 新版动态页归入「动态」分类

**行为修复**
- 页面分类改为每次执行实时读取 `location.href`：修复 v4「首页 SPA 跳进视频页后视频页规则（如 `.ebox`）永不生效」的问题

**移除**
- 评论区全部功能（评论/回复屏蔽、注入按钮、粉丝勋章、表情转文字）
- 白名单、大爆炸、直播间弹幕、消息中心回复（含自动删除）、相薄
- 动态正文/转发正文匹配（动态卡片按标题 + 作者走普通规则）
- manifest 注入范围收窄为 www / search / space / t 四域

**保留**
- BV→UP 主名异步查询（节流 + 风控闩锁 + 3 天缓存）
- 首页轮播/排行榜/热门/播放器推荐特殊处理
- 面板壳交互（右下角悬浮触发、520px 滑入、三按钮语义）

## 开发

要求：[bun](https://bun.sh) ≥ 1.x；E2E 需要本机安装 Edge。

```bash
bun install          # 安装 dev 依赖（仅 @playwright/test）
bun test             # 单元测试（138 例）
bun run test:cov     # + 覆盖率（纯函数模块 ≥ 84%）
bun run e2e          # E2E：真实加载扩展，fixture 劫持 bilibili 域名（无头，不弹窗）
E2E_HEADED=1 bun run e2e   # 有头模式调试
```

### 目录结构

```
src/content/        # 内容脚本（ES Modules，经 entry.js 动态 import 加载）
  entry.js          # classic 入口（MV3 content_scripts 不支持 module）
  main.js           # 引导装配
  config/           # 存储 v2：默认值/迁移(备份+写回)/作用域/正则序列化/chrome.storage 读写订阅/临时词条
  engine/           # 屏蔽引擎：页面分类、词条判定、时长解析、规则循环、rAF 调度
  rules/            # 23 条内置选择器规则（scopes 映射由单测钉死）
  resolver/         # BV → 用户名异步查询（节流 + 3 天缓存）
  panel/            # 设置面板：壳 + 分节（通用/词条/规则编辑器）+ 悬浮触发器
  pages/            # 首页特殊逻辑（轮播/排行榜/热门/播放器推荐）与翻页触发器
src/tools/          # 导入导出迁移页（接受 v1/v2 JSON）
test/unit/          # bun test 单元测试
test/fixtures/      # E2E 用静态 bilibili 页面骨架（www/搜索/视频卡片/动态）
test/e2e/           # Playwright 规格（真实加载扩展 + 路由劫持）
```

### 测试策略

- **单元测试**：作用域/分类/判定/时长/迁移/临时词条/内置规则表等纯函数模块（覆盖率见 `bun run test:cov`）
- **E2E**：Playwright 以 `--load-extension` 真实加载扩展，用 `context.route()` 把真实 bilibili 域名应答为本地 fixture，保证 URL 分类与页面逻辑在真实域名上执行；API 请求被拦截以保证密封性
